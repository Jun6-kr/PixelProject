## Work

- 기존 `QuadTree`가 분할과 액터 저장을 모두 담당하던 구조를 `QuadTree`와 `QuadNode`로 분리했습니다.
- `QuadNode`에 영역 판정, 자식 노드 분할, 액터 삽입·조회, 하위 노드 정리 기능을 구현했습니다.
- 경계에 걸친 액터는 현재 노드에 저장하고, 한 사분면에 완전히 포함된 액터만 해당 자식 노드에 삽입하도록 변경했습니다.
- `QuadTree`가 루트 노드의 생성·해제와 조회 결과 반환, 디버그용 노드 영역 수집을 담당하도록 재구성했습니다.
- 게임 레벨이 현재 화면 영역으로 QuadTree를 매 Tick 재생성하고 활성 액터를 삽입하도록 변경했습니다.
- 충돌 검사를 Block과 Damage 경로로 분리하고, 각 경로에 Brute Force 및 QuadTree 구현을 마련했습니다.
- Airman, AirShooter, Enemy 파일을 `MegaMan/Actor/Enemy` 폴더로 이동해 적 관련 코드를 정리했습니다.
- `HornPlatform`을 추가하고 Stage01에 HornPlatform과 Horn 두 개체를 배치했습니다.
- Horn이 일정 간격으로 높이를 변경하며 상승·하강하고, 플레이어와 충돌하면 2의 피해를 주도록 구현했습니다.
- 플레이어 피격 후 2초 동안 추가 피해를 받지 않고, 0.1초 간격으로 Sprite가 점멸하도록 구현했습니다.
- 기존 `HornObstacle` 클래스를 제거하고 프로젝트 파일 및 필터 구성을 갱신했습니다.

## Solved

- QuadTree 하위 노드에 소유권과 소멸 처리를 추가해 이전 구현의 비어 있던 `Clear` 및 하위 노드 정리 문제를 개선했습니다.
- 경계에 걸친 액터를 여러 자식 노드에 중복 삽입하지 않고 부모 노드에 보관하도록 변경했습니다.
- 충돌의 막힘 판정과 피해 판정을 별도 함수로 분리해 호출 목적을 명확하게 했습니다.
- 플레이어가 연속 충돌로 매 Tick 피해를 받는 문제를 피격 상태와 무적 시간으로 제한했습니다.

## Decision

- `[추론]` `QuadTree`는 외부 인터페이스와 루트 수명 관리를, `QuadNode`는 공간 분할과 액터 저장을 담당하도록 책임을 분리했습니다.
- `[추론]` 용량 임계치 기반 분할 대신 최대 깊이 5의 고정 깊이 분할 방식을 사용했습니다.
- Block 충돌과 Damage 충돌을 각각 독립적으로 조회하는 API를 사용하기로 했습니다.
- Horn은 별도 `HornObstacle`이 아니라 Enemy 기반 액터로 구현하고, 발판은 `HornPlatform`으로 분리했습니다.

## Issue

- `QuadNode::GetQuads`의 오른쪽 영역 판정식이 `targetBounds.GetXMax()`의 상한 비교 없이 값 자체를 조건으로 사용하므로 의도한 범위 검사인지 확인해야 합니다.
- QuadTree 영역을 그리는 `GameLevel::Draw` 코드는 현재 주석 처리되어 있어 커밋 메시지의 “시각화 기능 추가”가 실제 실행 상태인지는 확인이 필요합니다.
- QuadNode는 액터가 한 사분면에 포함되면 최대 깊이까지 즉시 분할하는 고정 깊이 구조이므로, 노드 수와 조회 비용을 측정해야 합니다.
- 플레이어 HP가 피해량 이하인 경우 사망 처리가 TODO로 남아 있고 HP 차감 없이 반환합니다.
- `Player`의 `bIsDamaged` 멤버가 추가됐지만 현재 코드에서는 사용되지 않습니다.
